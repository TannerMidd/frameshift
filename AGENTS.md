# Repository instructions

- Treat the zero-cost requirement in `docs/ENGINEERING_POLICY.md` as a hard
  project constraint. Do not introduce a required paid service, subscription,
  certificate, usage-priced API, or proprietary developer tool.
- Prefer free and open-source dependencies, local-first behavior, and the
  repository host's included automation features.
- Keep paid integrations optional only when the application retains a complete
  free path for building, testing, releasing, and normal use.
